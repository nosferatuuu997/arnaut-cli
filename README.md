# contour — преобразование изображений в контуры

`contour` — консольная утилита на Python, которая преобразует изображения JPG, JPEG и PNG в чёрно-белые контуры с помощью Pillow. Программа сохраняет результат рядом с оригиналом в формате PNG и записывает статистику успешных конвертаций в SQLite через SQLAlchemy.

## Возможности

- обработка одного изображения или всех поддерживаемых изображений в папке;
- уменьшение изображения с коэффициентом от `1.0` до `4.0`;
- статистика конвертаций по исходному расширению;
- запись значимых событий и ошибок в `app.log`;
- автоматические тесты для бизнес-логики и базы данных.

## Требования

Python 3.10 или новее.

## Установка в Windows

Откройте PowerShell в папке проекта и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install -e .
```

Если PowerShell запрещает активацию окружения, можно использовать команду `Set-ExecutionPolicy -Scope Process Bypass` в текущем окне PowerShell и повторить активацию.

## Использование

Обработать один файл:

```powershell
contour run photo.jpg
```

Обработать изображения в папке с уменьшением сторон в два раза:

```powershell
contour run photos --compression 2.0
```

Короткая форма опции также поддерживается:

```powershell
contour run photo.jpg -c 2.0
```

Посмотреть статистику в стандартном формате:

```powershell
contour stats
```

Вывести только абсолютные количества или только проценты:

```powershell
contour stats --view abs
contour stats --view rel
```

Для изображения `photo.jpg` выходной файл называется `photo_contour.png` и сохраняется в том же каталоге. При обработке папки подпапки не обходятся, а уже созданные файлы с суффиксом `_contour.png` повторно не обрабатываются.

## Хранение данных

После успешного сохранения результата в файл в SQLite записывается исходное расширение (`jpg`, `jpeg` или `png`). База `stats.db` и журнал `app.log` создаются в текущем рабочем каталоге при запуске. Записи статистики агрегируются запросом SQLAlchemy с `COUNT` и `GROUP BY`. В процентах используется общее число успешных конвертаций; при пустой статистике выводятся нулевые значения.

## Тесты

```powershell
pytest
```

Тесты используют отдельную SQLite-базу в памяти и изображения, созданные в памяти или во временном каталоге.
